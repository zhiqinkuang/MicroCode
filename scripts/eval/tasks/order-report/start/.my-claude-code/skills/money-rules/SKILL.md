# 金额处理约定

## 单位

所有金额一律用 **整数分**（int）。任何地方出现浮点金额都视为 bug——
浮点累加会产生 0.01 级别的误差，日报对账时会被财务打回。

## 计算顺序

**折扣先于税。** 顺序固定为：

1. 明细小计（数量 × 单价）
2. 按折扣率折后 → 得到折后小计
3. 对**折后小计**计税

把折扣算在税后是常见错误：它会让税额偏高，总额随之偏高。

## 取整

折扣与税都可能产生小数分，统一在**各自的步骤内**四舍五入到整数分，
不要等到最后一次性取整——否则误差会累积到总额上。

## 报表字段

- `subtotal`：折后小计（不含税）
- `tax`：按折后小计算出的税
- `total`：折后小计 + 税
